# Zanze Flavours Digital

LOVABLE PROMPT — CARIBBEAN FLAVAS JAMAICAN RESTAURANT WEBSITE

Build a complete, modern, premium, responsive restaurant website for a new Jamaican/Caribbean restaurant called Caribbean Flavas.

The restaurant is small and newly established, so the website should feel authentic, warm, youthful, exciting, premium, and welcoming, while remaining simple enough for customers to navigate within seconds.

The website should communicate:

Jamaican soul. Caribbean flavour. Modern experience.

The restaurant's identity should be built around bold food, island culture, good vibes, and great hospitality.

The website must use the provided Caribbean Flavas logo as the official brand logo.

1. BRAND IDENTITY

Use the uploaded Caribbean Flavas logo throughout the website.

The logo contains:

 Black background

 Gold/yellow lettering and accents

 Bright Caribbean blue/turquoise lettering

 Palm tree

 Spoon and fork

 Circular gold detailing

Use this logo as the primary inspiration for the site's visual identity.

Main color palette

Build the website around:

 Deep black

 Charcoal

 Warm Caribbean gold/yellow

 Turquoise/Caribbean blue

 White/cream

 Small amounts of tropical green

The colors should complement the logo rather than compete with it.

Important:

Do not make the entire website bright yellow, blue, green, or red.

Use the colors strategically.

The overall feeling should be:

Dark + elegant + tropical + energetic + appetizing.

2. DESIGN DIRECTION

The website should feel like a modern Jamaican restaurant brand, not a generic restaurant template.

Use:

 High-quality food photography

 Large appetizing food images

 Dark elegant backgrounds

 Gold accents

 Caribbean blue highlights

 Subtle tropical patterns

 Palm leaf details

 Subtle Jamaican-inspired textures

 Modern typography

 Spacious layouts

 Rounded cards where appropriate

 Smooth transitions

 Subtle animations

Do not overload the design with palm trees, Jamaican flags, or tropical decorations.

The Jamaican influence should be felt through the atmosphere, colors, food, imagery, typography, and language, not forced into every section.

15. QR CODE MENU

Because the restaurant will not have a physical menu, customers will use a QR code.

However, do NOT make the QR code a major feature of the website.

It would be unnecessary for customers already browsing the website.

Instead, create a discreet QR Menu area.

For example:

On the Menu page, include a small section near the bottom:

Already at Caribbean Flavas?

Scan our menu and explore what's available.

[QR CODE]

The QR code should be replaceable/uploadable.

Also include a small:

QR Menu

link in the footer.

Do NOT place a huge QR code in the hero section.

Do NOT make the QR code the first thing customers see.
